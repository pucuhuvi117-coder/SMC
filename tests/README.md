# Проверка сборки в TradingView

## v0.3.0 — что проверить

Сначала убедитесь, что загружена новая сборка: в первых строках файла `build 0.3.0`; в Ribbon первым сегментом идёт `HTF 4H ▲ BULL` (или другой ТФ). Если подписи зон выглядят как `FVG×3+BB+IFVG` — это старая сборка v0.1.

| # | Проверка | Ожидание |
|---|---|---|
| 1 | Обычный масштаб (150–300 баров, ETHUSDT 15m) | Левая половина экрана тоже размечена: завершённые зоны (светлая заливка, пунктирная рамка), пробои, снятая ликвидность, сессии |
| 2 | Отдалите график на 1000–3000 баров | Разметка распределена по всей ширине без пустых полос; в Debug-таблице `VIEW … · N seg`, пулы `BOXES/LINES/LABELS` не переполнены |
| 3 | Прокрутите далеко влево (несколько тысяч баров) | История есть и там; в Debug подсказка строки ZONES показывает, с какого бара хранится архив |
| 4 | Подписи активных зон | В колонке тегов справа от последней свечи (вместе с BSL/SSL, EQ, `◀ 63%`), не внутри боксов и не на свечах; близкие теги сливаются, при отдалении тоже |
| 5 | Подписи BOS / CHoCH | Начинаются от пивота и не заходят на свечи пробоя |
| 6 | Сессии на тёмно-синем фоне | Боксы Asia / London / NY хорошо видны: светлые оттенки, рамка, название над максимумом. При сильном отдалении названия у узких сессий скрываются — сессию определяет цвет. Прозрачность — «Session fill transparency» |
| 7 | Ribbon и Dashboard | Текст крупнее (настройка «Panel text size»), первый сегмент Ribbon — HTF; в Dashboard строка HTF |
| 8 | HTF-объекты | Линии `◆4H BOS↑` / `◆4H CHoCH↓` толщиной 2; зоны `◆4H OB` с рамкой; уровни `◆4H BSL` |
| 9 | HTF без перерисовки | Bar Replay через закрытие 4H-бара: HTF-объекты появляются на первом баре после закрытия HTF-бара и потом не меняются. То же на недельном графике через границу месяца (HTF = M) |
| 10 | Авто-HTF | M1 → 15m, M5 → 1H, M15/H1 → 4H, H4 → D, D → W; на месячном графике Ribbon пишет `HTF OFF` |
| 11 | Ручной HTF ниже ТФ графика (например, 15 на H1) | Ribbon: `⚠ HTF ≤ TF`, HTF-объектов нет |
| 12 | Молодой инструмент (мало истории на HTF) | Ribbon: `HTF 4H ⚠`, MARKET считается по структуре графика |
| 13 | MARKET в Dashboard | `MIXED`, когда HTF и структура графика расходятся или структура графика не определена при известном HTF |
| 14 | Алерты | Новые условия «HTF bias change» и «HTF BOS / CHoCH»; «BOS ↑ (swing)» не срабатывает от HTF-пробоев |
| 15 | Скорость | Пересчёт при прокрутке и масштабировании — не дольше 1–2 секунд (сообщите, если медленнее) |

# Проверка сборки в TradingView · v0.1.0

Сборка проверена только офлайн (синтаксис + lint). Это первая проверка компилятором TradingView, поэтому порядок такой: компиляция → смоук-тест → функциональные проверки.

## Шаг 1. Компиляция

1. Откройте Pine Editor → New → Indicator, удалите шаблон.
2. Вставьте всё содержимое `dist/SMC_Visualizer_Pro.pine` → **Add to chart**.
3. Если есть ошибка, пришлите текст ошибки и номер строки. Номер относится к файлу `dist/`, по нему находится модуль в `src/`.
4. Отдельно пришлите **предупреждения** (жёлтые), если они есть.

## Шаг 2. Смоук-тест (5 минут)

Инструмент: EURUSD или BTCUSD, ТФ M15, режим **Normal**.

| # | Проверка | Ожидание |
|---|---|---|
| 1 | Индикатор загрузился без runtime-ошибки | Нет красного значка ошибки у названия |
| 2 | Status line | Только «SMC Pro», без списка значений настроек |
| 3 | Ribbon внизу по центру | `STR ▲ BULL` / `STR ▼ BEAR`, сессия, `DISC/PREM %`, LIQ |
| 4 | Dashboard справа вверху | MARKET, STRUCTURE, SESSION, LOCATION, LIQUIDITY, TARGET ↑/↓ |
| 5 | Структура | Последние 3 swing BOS/CHoCH пунктиром с подписями |
| 6 | Ликвидность | Золотистые линии BSL/SSL с тегами справа; ◆PDH/◆PDL |
| 7 | Зоны | Не больше 2 OB и 2 FVG выше и ниже цены; FVG без рамки, OB с рамкой |
| 8 | Диапазон | Пунктир EQ, полупрозрачная полоса OTE, шкала-гейдж справа от цены |
| 9 | Режим **Clean** | Заметно меньше объектов, Dashboard скрыт, Ribbon остаётся |
| 10 | Режим **Analysis** | Появляются iBOS/iCHoCH, HH/HL, больше зон и история свипов |
| 11 | Режим **Debug** | Таблица слева: бюджеты, реестры, объём; на объектах #ID и R |
| 12 | Светлая тема | Цвета перестраиваются, текст читается |

## Шаг 3. Функциональные проверки

| Область | Что проверить | Критерий (docs §27) |
|---|---|---|
| No-repaint | Bar Replay 100+ баров: метки BOS/CHoCH, свипы и зоны не исчезают и не меняются после закрытия бара | AC-06 |
| Свип vs пробой | Тень за уровнем с закрытием обратно → `SSL ✕`/`BSL ✕`; закрытие за уровнем без возврата 2 бара → линия обрывается без ✕ | AC-14 |
| OB | Бокс стоит на последней противоположной свече перед импульсом к пробою | AC-17 |
| FVG | Бокс только при реальном разрыве; на открытии сессии акций (AAPL M15) гэп не размечается | AC-18 |
| Конверсия | Закрытие телом за дальней границей OB → BB или MB с пунктирной/точечной рамкой | AC-20 |
| Сессии | NY time: London KZ 02:00–05:00, NY AM KZ 07:00–10:00 в любое время года | AC-23 |
| PDH/PDL | Совпадают с high/low предыдущего дневного бара | AC-16 |
| Алерты | Создать алерт «BOS ↑ (swing)» — срабатывает только на закрытии бара | AC-07 |
| Производительность | Pine Profiler: время расчёта на M15 / 5000 баров | AC-03 |
| Debug-журнал | Advanced → «log events», Pine Logs: строки `EV|…` | §19.1 |
