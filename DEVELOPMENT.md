# Разработка SMC Visualizer Pro

Спецификация — `docs/`. Этот файл — как устроен код и как с ним работать.

## Сборка

```bash
python3 build/build.py            # src/*.pine → dist/SMC_Visualizer_Pro.pine + lint
python3 build/build.py --check    # + проверка синтаксиса (нужен pip-пакет pynescript)
```

- Pine не поддерживает `include`, а invite-only публикация — один файл. Поэтому исходники модульные, а публикуется собранный монолит (ADR-04).
- **`dist/` не редактируется руками.** Правки — только в `src/`, затем пересборка.
- Версия — в файле `VERSION`, подставляется в заголовок и константу `BUILD`.
- `--check` использует pynescript (ANTLR-парсер Pine). Он ловит синтаксис, но не типы и не ошибки времени выполнения: окончательная проверка — компилятор TradingView. На большом файле проверка идёт 2–3 минуты. Если pynescript установлен в другом окружении, укажите `PINE_PARSER_PYTHON=/path/to/python`.

### Правила lint (ошибка сборки)

| Правило | Почему |
|---|---|
| Нет `varip` | Детерминизм history = realtime (ADR-10) |
| Нет `timenow` | То же (§20.8) |
| `lookahead_on` только со смещением `[1]` | Иначе repaint (§4.7) |
| Отступы кратны 4, без табов, без переносов строк | Переносы в Pine требуют особых отступов; проект их не использует |
| Нет восходящего цикла до `size() - 1` без проверки | В Pine `for i = 0 to -1` выполняется дважды (0, −1) |

## Инварианты, которые нельзя нарушать

1. Логика меняет состояние только внутри `if barstate.isconfirmed` в `90_main`.
2. Модули `6x` и `95` только читают состояние. Relevance Score не используется логикой (ADR-11).
3. Все `ta.*`, `request.*`, пивоты — на глобальном уровне в `10_data`, на каждом баре. Функции движков читают их через `[]`.
4. Любое динамическое смещение `[]` меньше `MAXBACK_GUARD` (550). Буферы задаются через `max_bars_back` в `10_data`.
5. Новый порог задаётся в ATR или тиках, не в процентах цены.
6. Новое событие добавляется в `01_constants`, в `f_evName` и в каталог `docs/03-domain-models.md` §6.4.
7. Визуал берёт цвета и прозрачности только из `60_visual_tokens`.
