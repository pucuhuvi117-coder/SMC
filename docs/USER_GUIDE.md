# Руководство пользователя

**SMC Visualizer Pro** и **SMC Pro · Setups** для TradingView, версия 0.8.1.

Индикаторы аналитические: показывают структуру рынка и сетапы, но **ордера не выставляют**. Оценка сетапа показывает, насколько полно он собран, а не вероятность выигрыша.

## 1. Два индикатора

| | SMC Visualizer Pro | SMC Pro · Setups |
|---|---|---|
| Файл | `dist/SMC_Visualizer_Pro.pine` | `dist/SMC_Pro_Setups.pine` |
| Показывает | Структуру (BOS / CHoCH / MSS), ликвидность и свипы, OB и FVG, диапазон и OTE, сессии, старший ТФ, историю | Сетапы Sweep Reversal и Continuation: зону входа, Entry / SL / TP, оценку и грейд, путь сетапа |
| Панели | Context Ribbon, Dashboard, Debug-таблица | Панель Setup |
| Алерты | События структуры, ликвидности, зон, сессий, HTF | Сетапы: READY / TRIGGERED / INVALID, одно сообщение на бар (Text или JSON) |

Почему два: всё вместе не укладывается в лимит времени компиляции TradingView. Оба индикатора собраны **из одного кода движков**: сетапы строятся по той же разметке, что нарисована, если настройки движков совпадают (см. [cfg](#24-проверка-cfg)).

## 2. Установка

### 2.1 SMC Visualizer Pro
1. TradingView → **Pine Editor** → **New** → **Indicator**.
2. **Ctrl+A, Delete** — удалить шаблон редактора. Если его оставить, в скрипте будет два `indicator()` и ошибка CE10243.
3. Вставить содержимое `dist/SMC_Visualizer_Pro.pine` целиком → **Save** → **Add to chart**.

Компиляция идёт около минуты — это нормально.

### 2.2 SMC Pro · Setups
Так же: новый индикатор → **Ctrl+A, Delete** → вставить `dist/SMC_Pro_Setups.pine` → **Save** → **Add to chart**. Оба индикатора — на один график.

### 2.3 Обновление
Открыть сохранённый скрипт в Pine Editor → **Ctrl+A** → вставить новую версию → **Save**. Настройки на графике сохраняются, если не менялись их названия. После обновления **пересоздайте алерты**: алерт работает с той версией скрипта, на которой был создан.

### 2.4 Проверка cfg
Число **cfg** — подпись настроек движков (структура, ликвидность, OB, FVG, диапазон, сессии, HTF, Advanced):
- SMC Visualizer Pro: Dashboard, строка **CFG**;
- SMC Pro · Setups: панель Setup, строка **CFG**.

Числа должны совпадать. Если разные — где-то отличаются настройки групп 2–8 или 11, и сетапы строятся по другой разметке, чем нарисована. Визуальные настройки (режим, тема, видимость, панели) на cfg не влияют.

## 3. Режимы и общий вид

Группа **⚙️ 0 · PROFILE**, есть в обоих индикаторах.

| Режим | Для чего | Что видно |
|---|---|---|
| **Clean** | Исполнение | Минимум: последний слом, 1 зона на сторону, ключевые уровни. Сетапы грейда A и A+ |
| **Normal** (по умолчанию) | Ежедневный анализ | Структура, 2 зоны на сторону, свипы, сессии, Dashboard. Сетапы от грейда B, до 6 прошлых |
| **Analysis** | Разбор истории | Внутренняя структура, HH / HL / LH / LL, больше объектов, окно истории до 5000 баров. Все грейды, до 10 прошлых сетапов |
| **Debug** | Проверка | ID, состояния и Relevance на объектах, скрытые объекты, Debug-таблица, самопроверки |
| **Custom** | Своя настройка | Потолок Analysis, остальное решают флажки |

Режим — **потолок**: флажки ниже могут только скрыть то, что режим разрешает. Расчёты между режимами не меняются: сетапы и алерты одинаковы в любом режиме.

Остальное в группе:
- **Theme** — Auto берёт тёмную или светлую тему по фону графика.
- **Visibility** — общая плотность заливок и линий: Subtle светлее, Bold плотнее. Свечи всегда поверх.
- **Palette** — Color-blind safe: синий / оранжевый вместо зелёного / красного.

**🎨 1 · VISUAL EXPERIENCE** (SMC Visualizer Pro):
- **History view**: *History window* — разметка на последних «depth» барах, равномерно по окну; *Recent only* — только последние объекты у правого края.
- **depth (bars)** — глубина окна. По умолчанию 1500. Потолок задаёт режим: Clean 500, Normal 1500, Analysis 5000. Левее окна разметки нет — если нужно дальше, увеличьте глубину (загрузка станет дольше).
- **Label verbosity**: Icons (только стрелки у второстепенного), Short (`BOS↑`, `SSL ✕`), Full (с ценами и размерами).
- **Smart Labels** — теги у правого края, стоящие слишком близко, объединяются.
- **Max zones per side**, **Reduce Minor Liquidity / FVG / OB** — меньше второстепенных объектов.
- Context Ribbon, Dashboard (Compact / Expanded), размер текста панелей, шкала диапазона (Range Gauge).

## 4. Что нарисовано на графике (SMC Visualizer Pro)

### 4.1 Цвета
| Цвет (стандартная палитра) | Смысл |
|---|---|
| Зелёный | Бычье: направление вверх, бычьи зоны |
| Красный | Медвежье |
| Золотой | Ликвидность: уровни BSL / SSL, свипы |
| Синий | Сигнал: сетапы, OTE, POI |
| Фиолетовый | Mitigation Block |
| Серый | Нейтральное: EQ, отработанные и прошлые объекты |
| Оранжевый | Предупреждения в панелях |

Форма — тип объекта, прозрачность — состояние и важность, толщина — старший ТФ (2 px) или основной.

### 4.2 Структура
| Метка | Значение |
|---|---|
| `BOS↑` / `BOS↓` | Break of Structure — пробой swing-уровня по тренду |
| `CHoCH↑` / `CHoCH↓` | Change of Character — первый пробой против тренда |
| `MSS↑` / `MSS↓` | CHoCH с сильной ногой (≥ «MSS min leg displacement» ATR) — Market Structure Shift |
| `iBOS`, `iCHoCH` | То же для внутренней (internal) структуры, пунктир |
| `HH` `HL` `LH` `LL` | Swing-точки: higher high, higher low, lower high, lower low (Analysis) |
| `EQH` / `EQL` | Равные максимумы / минимумы |
| `◆4H BOS↑` | Префикс `◆ТФ` — объект старшего таймфрейма (2 px) |

Пробой засчитывается по **закрытию** свечи за уровнем (или по тени — настройка «Break confirmation»).

### 4.3 Ликвидность
| Метка | Значение |
|---|---|
| `BSL` / `SSL` | Buy-side (над максимумами) / sell-side (под минимумами) ликвидность |
| `BSL ≡3` | Уровень из 3 равных касаний |
| `BSL ?` | Закрытие за уровнем, ждём возврата (reclaim) — свип или пробой ещё не ясен |
| `◆PDH` `◆PDL` `◆PWH` `◆PWL` | Максимум / минимум прошлого дня и недели |
| `AH` `AL` · `LOH` `LOL` · `NYH` `NYL` | Максимумы и минимумы сессий Asia, London KZ, NY AM KZ |
| `✕` на уровне | **Свип**: цена сходила за уровень и вернулась (тенью или закрытием обратно в окне reclaim). Уровень гаснет |
| `TAKEN` (в панелях) | Уровень пробит и цена за ним закрепилась — это не свип |

### 4.4 Зоны
| Метка | Значение |
|---|---|
| `OB` | Order Block — последняя противоположная свеча перед импульсом, сломавшим структуру |
| `BB` | Breaker Block — пробитый OB, нога которого сняла внешнюю ликвидность; полярность меняется |
| `MB` | Mitigation Block — пробитый OB без снятия ликвидности (фиолетовый) |
| `FVG` | Fair Value Gap — разрыв между тенями 1-й и 3-й свечей импульса |
| `IFVG` | Inversion FVG — FVG, пробитый насквозь закрытием; работает в обратную сторону |
| `×2` | Две перекрывающиеся зоны одного типа слиты в одну |

Линия в середине — midline у OB и CE (50 %) у FVG. FVG сужается по мере заполнения («Shrink on fill»). OB тускнеет после митигации (правило «Mitigation rule»: касание, 50 % или полностью). Теги живых зон стоят в колонке у правого края, а не внутри зоны.

### 4.5 Диапазон, Premium / Discount, OTE
- **EQ** — середина текущего dealing range (`EQ~` — диапазон ещё формируется).
- Полоса **OTE** — зона оптимального входа (по умолчанию 0.62–0.79 от ноги).
- Выше EQ — Premium (там ищут шорты), ниже — Discount (лонги).
- **Шкала справа от цены** (Range Gauge): диапазон, EQ, OTE и тег `◀ 63%` — где сейчас цена в диапазоне.

### 4.6 Сессии
Прямоугольники по максимуму и минимуму сессии: **Asia**, **London KZ**, **NY AM KZ** (пресет ICT, время Нью-Йорка с учётом перехода на летнее время). Текущая сессия — сплошная рамка, прошлые — пунктир. Сессии считаются на графиках до 1H включительно.

## 5. Панели SMC Visualizer Pro

### 5.1 Context Ribbon (одна строка)
`HTF 4H ▲ BULL │ STR ▼ BEAR │ LON KZ 45m │ DISC 32% · OTE │ SSL ✕ 3b │ статус`

| Ячейка | Значение |
|---|---|
| HTF | Тренд старшего ТФ. `⚠` — мало подтверждённых HTF-баров для уверенного bias; `⚠ HTF ≤ TF` — ручной HTF не выше текущего ТФ |
| STR | Swing-тренд текущего ТФ; `◆ RANGE` — режим диапазона |
| Сессия | Активная killzone / сессия (`ASIA`, `LON KZ`, `NY KZ`) и сколько минут осталось; `NO KZ` — вне них |
| PD | Положение в диапазоне: PREM / EQ / DISC и процент, `· OTE` — цена в OTE |
| LIQ | Последнее событие ликвидности за 20 баров: `✕` — свип, `TAKEN` — пробой, `3b` — сколько баров назад |
| Статус | `WARMING UP` (первые бары, сигналы и алерты подавлены) или `⚠ NON-STANDARD CHART` (Heikin Ashi, Renko и т. п.) |

### 5.2 Dashboard
**Compact**: MARKET, HTF, STRUCTURE, SESSION, LOCATION, LIQUIDITY, TARGET ↑ / ↓ (ближайшая крупная ликвидность сверху / снизу и расстояние в ATR), CFG. **Expanded** добавляет INTERNAL (тренд внутренней структуры) и MODE, а в Analysis / Debug — 5 последних swing-событий с датой. Подсказки (навести курсор на значение) объясняют каждую строку.

MARKET: `BULLISH` / `BEARISH`, если HTF и структура графика согласны; `MIXED` — не согласны; `RANGING` — режим диапазона.

### 5.3 Debug-таблица (режим Debug)
BUILD (версия, режим, cfg), BARS, VIEW (окно и сегменты), ZONES / LEVELS (живые / всего / архив), EVENTS, BOXES / LINES / LABELS (занято / размер пула, лимит платформы 500), **ASSERTS** (нарушения самопроверок), VOLUME, CHART, LENGTHS, SESSIONS, HTF.

## 6. Сетапы (SMC Pro · Setups)

### 6.1 Модели
- **Sweep Reversal**: свип ликвидности → CHoCH / MSS против него (в окне «Shift window», с ногой ≥ «min leg ×ATR») → FVG или OB этой ноги в discount (лонг) / premium (шорт) → вход.
- **Continuation**: BOS по тренду → FVG или OB этой ноги в discount / premium → вход.

### 6.2 Жизненный цикл
```
SWEEP_SEEN → SHIFTED → FORMING → READY → TRIGGERED → TP1 → TP2 → WIN
                                    ↘ INVALID / EXPIRED / MISSED      ↘ SL
```
| Стадия в панели | Стадии движка | Что происходит |
|---|---|---|
| — watching | — | Сетапа нет; панель показывает ближайшую ликвидность, за которой следим |
| FORMING | SWEEP_SEEN, SHIFTED, FORMING | Свип и сдвиг есть, выбрана POI; план и оценка проверяются на каждом баре |
| READY | READY | План готов, грейд ≥ порога пресета. Ждём касания Entry |
| ACTIVE | TRIGGERED, TP1, TP2 | Вход был. После TP1 стоп переносится в безубыток (флажок «Move SL to entry after TP1») |
| DONE | WIN, SL, INVALID, EXPIRED, MISSED | WIN — дошли хотя бы до TP1; SL — стоп; остальные — сделки не было |

До входа сетап отменяется закрытием за уровнем инвалидации, противоположным swing-CHoCH или пробитой POI.

### 6.3 Композиция на графике
- **Рамка POI** (синяя, 2 px) — зона входа поверх той зоны, которую рисует SMC Visualizer Pro. Пунктир — сетап ещё формируется или закончился без сделки.
- **Entry** (сплошная синяя), **SL** (красная), **TP1–TP3** (зелёный пунктир, справа `TP1 1.2345 · 2.1R`, `✓` — цель взята).
- Заливки риск / прибыль (кроме Clean).
- Красная точечная линия — **инвалидация** (если отличается от стопа на буфер), пока ждём вход.
- `●` — момент входа.
- **Карточка** справа: `LONG · A 7.2   E 1.2345`, цепочка `Sweep → CHoCH → FVG → OTE`, `RR 1:2.8 · SL 1.1 ATR`. Подсказка карточки — полный разбор баллов и план.
- Закончившийся сетап: цвет исхода (`✓ +2.1R` зелёным, `✕ SL` красным); без сделки — серый пунктир.

**Setup Path** (флажок, в Clean выключен): `① SSL ✕` на свипе → `② CHoCH↑ 1.8 ATR` на пробитом уровне → `③ FVG · OTE` на зоне → `④` на входе, соединены пунктиром. Это те самые свип, слом и зона, которые нарисованы в SMC Visualizer Pro.

### 6.4 Оценка (0–10) и грейд
| Фактор | Максимум | За что |
|---|---|---|
| Context | 3.0 | HTF по направлению +1.5 (против: −1.5); POI в discount / premium +0.75; в OTE +0.75 |
| Liquidity | 2.5 | Свип: major +2.0, minor +1.3; в Continuation — снятая внутренняя ликвидность +1.0; есть цель-ликвидность +0.5 |
| Structure | 2.0 | Swing-слом +1.0 (internal +0.5) плюс сила ноги (до +1.0 при 2 ATR) |
| POI | 1.5 | FVG ∩ OB +1.0 (одна зона +0.6); внутри зоны старшего ТФ +0.5 |
| Time | 0.5 | Сдвиг в killzone |
| Risk | 0.5 | RR ≥ 3 +0.5, ≥ 2 +0.25 |
| Штрафы | — | Зона HTF против до TP1 −1.0; Continuation в диапазоне −0.5 |

Грейды: **A+** ≥ 8.0 · **A** ≥ 6.5 · **B** ≥ 5.0 · **C** ниже. На графиках без killzone (ТФ выше 1H или London и NY выключены) остальные факторы умножаются на 10 / 9.5 — в разборе это строка `no killzones on this timeframe: factors ×1.05`.

**Scoring preset**:
- Balanced — READY от грейда B.
- Conservative — READY от A; сетапы против HTF или с зоной HTF против ближе 1R отклоняются.
- Aggressive — READY от C; killzone и HTF-POI считаются вдвое, штраф за HTF против −1.0.

Фильтр отображения: «Min grade to show» плюс потолок режима (Clean — A и A+, Normal — от B).

### 6.5 План сделки
- **Entry**: CE (середина POI), Zone edge (ближний край), OTE 0.705 (уровень 0.705, если он внутри POI).
- **SL**: Auto — за свипом (Reversal) или за защищённым swing (Continuation); Beyond POI; ATR × 1.5. Плюс буфер: больший из «SL buffer ×ATR» и «ticks», плюс спред.
- **Targets**: Liquidity — TP1 ближайшая противоположная ликвидность не ближе 1R, TP2 крупная ликвидность или край диапазона, TP3 уровень HTF / ключевой; чего нет — 1R / 2R / 3R. Или RR 1 / 2 / 3.
- Ограничения: «Min RR» (до последней цели), «Max SL ×ATR», «Min SL ticks», «Expiry» (сколько баров сетап может быть FORMING или READY).
- **Require HTF alignment** — только по направлению HTF. **Require killzone** — сдвиг только в London / NY killzone, READY истекает с концом killzone.

### 6.6 Причины, по которым сетап закончился без сделки
| Код | Что значит |
|---|---|
| `SWEEP_FAILED` | Закрытие за экстремумом свипа — свип не удержался |
| `NO_SHIFT_IN_WINDOW` | За «Shift window» баров не было CHoCH / BOS против свипа |
| `NO_POI` | У ноги сдвига нет свежих FVG / OB |
| `POI_IN_PREMIUM` / `POI_IN_DISCOUNT` | Зоны есть, но в «не той» половине диапазона |
| `SL_INVALID` / `SL_TOO_TIGHT` / `SL_TOO_WIDE` | Стоп некорректен, меньше «Min SL ticks» или больше «Max SL ×ATR» |
| `RR_LOW` | RR до последней цели ниже «Min RR» |
| `GRADE_LOW` | Оценка ниже порога пресета |
| `HTF_ZONE_NEAR` | Conservative: зона HTF против ближе 1R |
| `CLOSE_BEYOND` | Закрытие за уровнем инвалидации |
| `OPPOSITE_CHOCH` | Противоположный swing-CHoCH |
| `POI_BROKEN` | Зона входа пробита |
| `TP1_BEFORE_ENTRY` | Цена дошла до TP1, не коснувшись входа (MISSED) |
| `EXPIRY` | Истёк «Expiry» |
| `SESSION_END` | С «Require killzone»: killzone закончилась |

Если сетап в FORMING ждёт, в подсказке строки SETUP будет `waiting: rr low` и т. п. — та же причина в нижнем регистре.

### 6.7 Панель Setup
| Строка | Значение |
|---|---|
| SETUP | `LONG — READY · Reversal` или `— watching SSL 1.2345`. Подсказка: модель, цепочка, сколько баров до истечения, чего ждём |
| QUALITY | `7.2 / 10 · A ▮▮▮▮▮▮▮▯▯▯`, подсказка — разбор баллов |
| PLAN | `E · SL · TP1`, подсказка — все цели с RR и инвалидация |
| INVALID | Уровень, закрытие за которым отменяет сетап до входа |
| STATUS | WARMING UP / NON-STANDARD CHART |
| INSPECT | См. ниже |
| STATS | По всей загруженной истории: `READY 24 · ✓9 ✕7 · no_poi 31` — дошли до READY, выиграли (хотя бы TP1), стоп, и самая частая причина неудачи. В подсказке — все счётчики |
| CFG | Подпись настроек и версия |

**Price-scale markers** — Entry, SL и TP1 фокусного сетапа как значения на шкале цены.

### 6.8 Inspect — «что было в этой точке»
Включить «Inspect» и выбрать время рядом с флажком. Сетап, живший в этот момент, рисуется полностью с путём, даже если его грейд ниже фильтра. Строка **INSPECT** — сторона, стадия, модель, грейд; подсказка — разбор и план. Если сетапа не было — `no setup · …`: попытки, закончившиеся без сделки, с причинами (хранятся последние 400), или что ни свипа со сдвигом, ни BOS по тренду тогда не было.

## 7. Алерты и webhook

Алерты срабатывают только на **закрытии бара** и не перерисовываются.

### 7.1 SMC Visualizer Pro
Алерт → Condition: **SMC Visualizer Pro** → одно из событий: BOS ↑ / ↓ (swing), CHoCH ↑ / ↓ (swing), Sweep ↑ (SSL swept) / ↓ (BSL swept), Order block touch, FVG filled, Session / killzone start, Premium / discount change, HTF bias change, HTF BOS / CHoCH, OTE entered.

### 7.2 SMC Pro · Setups
- Отдельные условия: **Setup READY** (грейд ≥ «Alert min grade»), **Setup TRIGGERED**, **Setup INVALID**.
- Или один алерт **«Any alert() function call»**: одно сообщение на закрытие бара со всеми событиями, прошедшими фильтры (группа **🔔 10 · ALERTS & WEBHOOK**):
  - **Alert message**: Text — одна читаемая строка; JSON (webhook) — конверт `smcvp.event` v1 с планом сделки.
  - **Events**: Setups (переходы сетапов от READY, грейд ≥ Alert min grade); Setups + key events (плюс swing BOS / CHoCH, крупные свипы, смена HTF bias); All events (всё до «min tier», 1 — самое важное).
  - **Snapshot every N bars** — на барах без событий отправлять текущие READY / ACTIVE сетапы (heartbeat для шлюза). 0 — выключено.
  - **Sender id (tok)** — необязательный идентификатор для проверки на шлюзе. Не секрет брокера.
  - **Max message length** — не поместившиеся события отбрасываются, в JSON будет `"truncated": true`.
- После смены настроек **пересоздайте алерт**.

Формат JSON — [`docs/03-domain-models.md` §12](03-domain-models.md#12-webhook-model).

## 8. Скорость и ограничения

- **Отрисовка — на последнем историческом баре и один раз на закрытии каждого бара.** Между закрытиями ничего не перерисовывается; панели описывают последний закрытый бар.
- **Прокрутка и зум не пересчитывают скрипт.** Цена этого: история рисуется по окну последних «depth» баров, а не по видимой области, и левее окна разметки нет. Ширина подписей рассчитана на обычный масштаб (~200 баров на экране): при сильном отдалении подписи могут наезжать, при сильном приближении часть коротких подписей заменяется стрелкой.
- **Старший ТФ без repaint**: используются только закрытые HTF-бары.
- **Прогрев**: первые max(300, 20 × swing length) баров сигналы и алерты подавлены (`WARMING UP`).
- **Лимит TradingView** — 500 боксов, линий и меток на скрипт. Режимы держат объёмы ниже лимита; Debug-таблица показывает занятость.
- Нестандартные графики (Heikin Ashi, Renko, Kagi, Range и т. п.) строят структуру по синтетическим ценам — предупреждение `⚠ NON-STANDARD CHART`.

## 9. Решение проблем

| Симптом | Причина | Что сделать |
|---|---|---|
| CE10243 «Your script has 2 …» | В редакторе остался шаблон с `indicator()` | Ctrl+A, Delete и вставить файл заново |
| «Pine compilation was timed out» | Компилятор TradingView не уложился в 2 мин | Повторить Save. Если повторяется — сообщить версию и какой файл |
| Ошибка компиляции | — | Прислать текст ошибки, **имя файла** и номер строки |
| Предупреждения CW10003 / CW10013 | В текущей версии не ожидаются | Прислать список (версия, файл, строки) |
| cfg в панелях разные | Отличаются настройки движков | Выровнять группы 2–8 и 11 в обоих индикаторах |
| Сетапов не видно | Фильтр грейда, режим, прогрев | Normal или Analysis, «Min grade to show» = C, флажок «Setup engine», дождаться конца WARMING UP. Строка STATS покажет, сколько сетапов было и почему они отпали |
| Сетапы видны, но рамки еле заметны | Visibility = Subtle | Visibility = Standard или Bold |
| Нет сессий | ТФ выше 1H | Сессии считаются на 1H и ниже |
| `HTF ⚠` | Мало подтверждённых HTF-баров | Загрузить больше истории или выбрать HTF ниже |
| `⚠ HTF ≤ TF` | Ручной HTF не выше ТФ графика | Higher timeframe = Auto или ТФ выше текущего |
| `VOLUME none` в Debug | У инструмента нет объёма | Фильтры по объёму отключены автоматически |
| Слева нет разметки | Окно истории | Увеличить «depth (bars)» (или режим Analysis) |
| `ASSERTS` > 0 / `⚠N asserts` | Нарушена самопроверка | Pine Logs → строки `ASSERT|…`, прислать их |
| INSPECT: `no setup` | В выбранный момент сетапа не было | Подсказка строки объясняет, какие попытки были и почему отпали |
