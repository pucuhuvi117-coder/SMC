## Разработка индикатора "SMC Visualizer Pro" для TradingView (Pine Script v6)

---

| **Платформа** | TradingView |

| **Цель** | Полноценная автоматическая отрисовка всех ключевых элементов концепции Smart Money Concepts (SMC/ICT) для профессионального анализа рыночной структуры, ликвидности и точек входа |

### 2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

Индикатор состоит из **12 независимых модулей**, каждый включается/выключается отдельно через настройки.

---

#### МОДУЛЬ 1. Структура рынка (Market Structure)

**1.1. Определение свинговых точек**
- `ta.pivothigh()` / `ta.pivotlow()` с параметром `Pivot Lookback` (по умолчанию 5, диапазон 2–50).
- Подтверждение только после закрытия N свечей справа (без перерисовки).
- Опция отображения внутренней структуры (Internal Structure) с отдельным lookback.

**1.2. Определение тренда**
- Восходящий: серия HH + HL.
- Нисходящий: серия LH + LL.
- Боковик: отсутствие чёткой последовательности.
- Опция: определение тренда через `ta.supertrend` или EMA-фильтр.

**1.3. BOS (Break of Structure)**
- **BOS Bullish** — закрытие выше последнего свинг-хая в восходящем тренде.
- **BOS Bearish** — закрытие ниже последнего свинг-лоя в нисходящем тренде.
- Визуал: пунктирная линия от уровня свинга до точки пробоя + метка "BOS".

**1.4. CHoCH (Change of Character)**
- **CHoCH Bullish** — пробой вверх последнего свинг-хая в нисходящем тренде.
- **CHoCH Bearish** — пробой вниз последнего свинг-лоя в восходящем тренде.
- Визуал: метка "CHoCH" соответствующего цвета.

**1.5. Внутренняя и внешняя структура (Internal / External)**
- Разделение на два уровня: мажорная (HTF) и минорная (LTF) структура.
- Отдельные цвета и lookback для каждого уровня.

**1.6. Swing Points (HH/HL/LH/LL)**
- Автоматическая разметка всех свингов буквенными метками: HH, HL, LH, LL.
- Опция отображения только значимых свингов.

**1.7. Настройки модуля**
- `Show BOS/CHoCH` (bool)
- `Show Swing Labels` (bool)
- `Pivot Lookback` (int)
- `Internal Structure Lookback` (int)
- Цвета для бычьих/медвежьих сигналов

---

#### МОДУЛЬ 2. Order Blocks (OB)

**2.1. Бычий Order Block**
- Последняя медвежья свеча перед импульсом к BOS/CHoCH вверх.
- Зона: `low` → `high` (или `open` → `low`, настраиваемо).

**2.2. Медвежий Order Block**
- Последняя бычья свеча перед импульсом к BOS/CHoCH вниз.

**2.3. Типы OB**
- **Classic OB** — обычный.
- **Breaker Block** — OB, который был пробит, но стал поддержкой/сопротивлением.
- **Mitigation Block** — OB, который уже отработан.
- **Rejection Block** — OB с длинной тенью и малым телом.

**2.4. Фильтрация**
- `Volume Filter` (bool) — объём > SMA(volume, 20) × множитель (по умолчанию 1.5).
- `Max Lookback Bars` (int, по умолчанию 10).
- `Min OB Size (x ATR)` (float, по умолчанию 0.5).
- `Show Mitigated OB` (bool).

**2.5. Отрисовка**
- `box` от уровня OB до правого края + 10 баров.
- Бычий — зелёный 85%, медвежий — красный 85%.
- Автоудаление при mitigation.
- Лимит: 500 активных боксов.
- Опция: mid-line OB (50% уровня).

---

#### МОДУЛЬ 3. Fair Value Gaps (FVG) / Imbalance

**3.1. Бычий FVG**
- Трёхсвечная формация: `low[0] > high[2]`.

**3.2. Медвежий FVG**
- `high[0] < low[2]`.

**3.3. Типы FVG**
- **FVG** — классический трёхсвечный гэп.
- **Volume Imbalance (VI)** — разрыв между телами свечей без гэпа по теням.
- **Liquidity Void (LV)** — крупный разрыв с длинными тенями.
- **Balanced Price Range (BPR)** — перекрытие бычьего и медвежьего FVG.

**3.4. Фильтрация**
- `Min FVG Size (x ATR)` (float, по умолчанию 0.3).
- `Auto-fill FVG` (bool) — удалять после заполнения.
- `Show Consequent Encroachment (CE)` (bool) — линия 50% FVG.

**3.5. Отрисовка**
- `box` от `high[2]` до `low[0]` (бычий) и наоборот.
- Цвет: жёлтый/оранжевый 80%.
- Лимит: 500 активных боксов.

---

#### МОДУЛЬ 4. Liquidity Sweeps (Свипы ликвидности)

**4.1. Бычий свип**
- Свеча пробивает `low` предыдущего свинг-лоя, закрывается выше.

**4.2. Медвежий свип**
- Свеча пробивает `high` предыдущего свинг-хая, закрывается ниже.

**4.3. Типы свипов**
- **Stop Hunt** — резкий прокол с возвратом.
- **Liquidity Grab** — плавный забор ликвидности.
- **Turtle Soup** — свип с последующим разворотом.

**4.4. Отрисовка**
- Метка "SWEEP" со стрелкой в точке прокола.
- Опция: горизонтальная линия от уровня до свечи свипа.
- Зона свипа (box) с настраиваемым расширением.

**4.5. Настройки**
- `Show Sweeps` (bool)
- `Max Sweep Distance` (int)
- `Show Sweep Zones` (bool)

---

#### МОДУЛЬ 5. Liquidity Levels (Уровни ликвидности)

**5.1. Equal Highs / Equal Lows (EQH/EQL)**
- Определение равных максимумов/минимумов с допуском (по умолчанию 0.1% от цены).
- Отрисовка горизонтальных линий с меткой "EQH"/"EQL".

**5.2. Old Highs / Old Lows**
- Уровни предыдущих значимых свингов, которые ещё не пробиты.

**5.3. Buy-side / Sell-side Liquidity**
- Автоматическая разметка зон скопления стопов.
- Цветовая дифференциация: buy-side (выше цены) — красный, sell-side (ниже) — зелёный.

**5.4. Trendlines (Liquidity Trendlines)**
- Автоматическое построение трендовых линий по свингам.
- Отображение проколов трендовых линий как свипов.

---

#### МОДУЛЬ 6. Premium / Discount Zones (OTE)

**6.1. Dealing Range**
- Автоматическое определение торгового диапазона (последний свинг high → low).

**6.2. Разметка зон**
- **Premium** (верхние 50%) — зона продаж.
- **Discount** (нижние 50%) — зона покупок.
- **Equilibrium** (50%) — линия равновесия.

**6.3. Optimal Trade Entry (OTE)**
- Уровни Фибоначчи: 0.618, 0.705, 0.786 внутри зоны Discount (для лонгов) / Premium (для шортов).
- Отрисовка зоны OTE прямоугольником.

**6.4. Настройки**
- `Show Premium/Discount` (bool)
- `Show OTE` (bool)
- `Show Equilibrium` (bool)

---

#### МОДУЛЬ 7. Killzones (Временные зоны)

**7.1. Азиатская сессия**
- По умолчанию: 00:00–06:00 UTC (настраиваемо).
- Цвет: серый 90%.

**7.2. Лондонская сессия (Killzone)**
- По умолчанию: 07:00–10:00 UTC.
- Цвет: синий 90%.

**7.3. Нью-Йоркская сессия (Killzone)**
- По умолчанию: 12:00–15:00 UTC.
- Цвет: оранжевый 90%.

**7.4. Silver Bullet**
- 10:00–11:00 NY time.
- Отдельная подсветка.

**7.5. Judas Swing**
- Первый час Лондона/NY — зона ложного движения.

**7.6. Настройки**
- Отдельные тумблеры для каждой сессии.
- Настраиваемое время начала/конца.
- Опция: подсветка фона (bgcolor) вместо боксов.

---

#### МОДУЛЬ 8. Mitigation Blocks & Breaker Blocks

**8.1. Mitigation Block**
- OB, который был частично отработан, но остаётся валидным.

**8.2. Breaker Block**
- OB, который был пробит и сменил полярность (бычий → медвежий или наоборот).

**8.3. Отрисовка**
- Отдельный цвет: фиолетовый для mitigation, голубой для breaker.
- Метки "MB" и "BB" соответственно.

---

#### МОДУЛЬ 9. Supply & Demand Zones

**9.1. Drop-Base-Rally (DBR)**
- Классическая зона спроса.

**9.2. Rally-Base-Drop (RBD)**
- Классическая зона предложения.

**9.3. Drop-Base-Drop (DBD)**
- Зона продолжения падения.

**9.4. Rally-Base-Rally (RBR)**
- Зона продолжения роста.

**9.5. Фильтрация**
- `Base Length` (int) — количество свечей в базе (по умолчанию 1–5).
- `Min Zone Size (x ATR)`.
- `Fresh Zone Only` (bool) — показывать только непроверенные зоны.

**9.6. Отрисовка**
- `box` с градиентом или однотонным цветом.
- Метка типа зоны (DBR/RBD/DBD/RBR).

---

#### МОДУЛЬ 10. Multi-Timeframe (MTF) Analysis

**10.1. HTF Structure**
- Отображение BOS/CHoCH со старшего таймфрейма (настраиваемый: 4H, D, W).
- Использование `request.security()` с `lookahead=barmerge.lookahead_off`.

**10.2. HTF Order Blocks**
- OB со старшего ТФ, спроецированные на текущий график.
- Отдельный цвет и толщина границ.

**10.3. HTF FVG**
- FVG со старшего ТФ.

**10.4. HTF Liquidity**
- EQH/EQL со старшего ТФ.

**10.5. Настройки**
- `HTF Timeframe` (input.timeframe).
- Отдельные тумблеры для каждого типа объектов.
- Опция: показывать только активные (непробитые) HTF-уровни.

---

#### МОДУЛЬ 11. Алeрты и уведомления

**11.1. Alert Conditions**
- `alertcondition()` для каждого типа события:
  - BOS Bullish / Bearish
  - CHoCH Bullish / Bearish
  - Касание OB
  - Заполнение FVG
  - Liquidity Sweep
  - Вход в Killzone
  - Вход в зону Premium/Discount
  - Вход в OTE

**11.2. Динамические алерты**
- `alert()` с динамическим сообщением (тикер, ТФ, тип события, цена).

**11.3. Webhook-совместимость**
- Формат JSON для интеграции с внешними ботами.

**11.4. Настройки**
- Тумблер для каждого алерта.
- Опция: только на закрытии свечи (`barstate.isconfirmed`).

---

#### МОДУЛЬ 12. Dashboard (Информационная панель)

**12.1. Текущее состояние рынка**
- Тренд (Bullish/Bearish/Ranging).
- Активная сессия (Asia/London/NY).
- Позиция в диапазоне (Premium/Discount/Equilibrium).

**12.2. Статистика**
- Количество активных OB, FVG, свипов.
- Ближайший уровень ликвидности.
- Ближайший HTF-уровень.

**12.3. Последние сигналы**
- Список последних 5 событий (BOS/CHoCH/Sweep) с ценой и временем.

**12.4. Настройки**
- Позиция панели (Top-Left / Top-Right / Bottom-Left / Bottom-Right).
- Размер шрифта.
- Прозрачность фона.

### 5. КРИТЕРИИ ПРИЁМКИ (Acceptance Criteria)

✅ **AC-1.** Индикатор компилируется без ошибок в Pine Script v6.

✅ **AC-2.** Сигналы BOS/CHoCH не перерисовываются после закрытия свечи.

✅ **AC-3.** Order Block корректно определяется как последняя противоположная свеча перед импульсом к BOS.

✅ **AC-4.** FVG отрисовывается только при наличии реального разрыва между `low[0]` и `high[2]`.

✅ **AC-5.** При mitigation OB или заполнении FVG зона удаляется/меняет цвет согласно настройкам.

✅ **AC-6.** Количество объектов не превышает лимитов TradingView (500/500/500).

✅ **AC-7.** При изменении `Pivot Lookback` свинги пересчитываются корректно.

✅ **AC-8.** Алерты срабатывают на закрытии свечи.

✅ **AC-9.** HTF-объекты корректно проецируются без repaint (`lookahead_off`).

✅ **AC-10.** Killzones корректно отображаются с учётом таймзоны пользователя.

✅ **AC-11.** Premium/Discount зоны автоматически обновляются при смене диапазона.

✅ **AC-12.** Dashboard отображает актуальную информацию без задержек.

✅ **AC-13.** Все 12 модулей можно включать/выключать независимо.

✅ **AC-14.** Индикатор работает без ошибок на ТФ от M1 до MN.

✅ **AC-15.** Webhook-алерты отправляют корректный JSON.
